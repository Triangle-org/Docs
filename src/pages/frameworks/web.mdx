# Web — HTTP-сборка

`triangle/web` — приложение-шаблон HTTP-трека Triangle. Оно собирает `triangle/engine`, `triangle/engine-http`, Console, Router, Middleware, Database, Session, View и Events поверх Localzet Server. Точные требования к PHP и Composer-зависимостям приведены в [матрице совместимости](/compatibility).

## Маршрут запроса

**Клиент → Localzet Server → Engine HTTP → Middleware → Router → контроллер/callback → Response.**
Server принимает соединение и передаёт HTTP lifecycle движку; Router выбирает обработчик, а Middleware оборачивает его выполнение.

## Структура шаблона

- `app/controller/` — обработчики приложения; шаблон использует namespace `app\controller`.
- `app/middleware/` — прикладные middleware.
- `app/model/` — модели приложения, если оно использует Eloquent.
- `app/view/` — представления.
- `config/route.php` — исполняемый PHP, регистрирующий маршруты.
- `config/server.php` — listener, handler и настройки master/worker.
- `config/database.php`, `config/session.php`, `config/view.php` — настройки соответствующих модулей.
- `master` — CLI entry point приложения.

## Запуск

```bash
php master start
php master status
```

Шаблон слушает `http://127.0.0.1:8000`; адрес берётся из `SERVER_LISTEN` или `config/server.php`. Доступность команд и флагов зависит от версии Console в установленном lock-файле.

## Маршрут

Шаблонные маршруты объявляются через Triangle Router:

```php
use Triangle\Request;
use Triangle\Response;
use Triangle\Router;

Router::get('/hello/{name}', function (Request $request, string $name): Response {
    return response("Привет, $name!");
});
```

Для запуска нового проекта см. [быстрый старт](/quickstart) и используйте примеры из этой документации: namespace и lifecycle зависят от версии Triangle.

## Граница совместимости

Web, Web-Managed и Full имеют одинаковое имя Composer-пакета `triangle/web`, но различаются составом и ограничениями зависимостей. Composer не различает их по package name. Для установки через `composer create-project` используйте Web; остальные варианты выбираются как исходные шаблоны.
