# Web-Managed — вариант HTTP-шаблона

Web-Managed — отдельный исходный вариант HTTP-приложения Triangle. Он использует те же основные компоненты, что Web, но задаёт другие ограничения Engine и View и отличается точкой входа `master` и конфигурационными примерами.

У Web-Managed то же Composer-имя `triangle/web`, что у Web. Composer не может выбрать эти варианты по package name: `composer create-project triangle/web` устанавливает основной Web-шаблон. Если вашему проекту нужны зависимости Web-Managed, используйте соответствующий исходный репозиторий и зафиксируйте его Composer lock.

Установка и общая структура описаны в руководстве [Web](/frameworks/web); точные различия зависимостей — в [матрице совместимости](/compatibility).
