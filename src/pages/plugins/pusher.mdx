# Pusher — прототип

`triangle/pusher` пока не является рабочим push-сервисом. Пакет объявляет зависимости от Triangle Engine и Router, однако process handler не реализует отправку событий, а маршрут обращается к отсутствующему классу `Api`.

Конфигурация отключена по умолчанию. Не включайте process config и не публикуйте маршруты плагина: в текущем состоянии пакет не реализует готовый протокол, авторизацию запросов и обработку событий.

Для актуального состояния зависимостей см. [матрицу совместимости](/compatibility).
