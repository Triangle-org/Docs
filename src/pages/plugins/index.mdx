# Плагины

Плагины подключают дополнительные возможности к приложению Triangle или Localzet Server. Наличие Composer-пакета не означает, что любая функция или интеграция плагина готова к production.

## OAuth

`triangle/oauth` использует Localzet HTTP client и Triangle Engine. Смотрите страницу [OAuth](/plugins/oauth) и проверяйте поддержку конкретного провайдера: его endpoints и требования могут изменяться независимо от пакета.

## Media — обработка изображений

`triangle/media` требует PHP Imagick extension. Установите Imagick для используемой версии PHP; обзор API и рекомендации по upload-маршрутам — на странице [Media](/plugins/media).

## Pusher — незавершённый каркас

Плагин остаётся прототипом: конфигурация отключена по умолчанию, а полноценная обработка push-событий не реализована. Не используйте его как готовый push-сервис; подробности — на странице [Pusher](/plugins/pusher).

## MultiConnect — Localzet Server connection registry

`triangle/multiconnect` зависит от Localzet Server и предоставляет `GatewayServer` с реестром соединений, UID и групп внутри worker-процесса. Обработчик можно зарегистрировать как endpoint Localzet Server или явно добавить в `config/process.php` Triangle-приложения. Пакет можно использовать вне Triangle; пример подключения приведён в [руководстве MultiConnect](/plugins/multiconnect).

Локальный реестр видит соединения только текущего worker-процесса. Для распределённой отправки пакет содержит необязательный адаптер к `localzet/cluster`, чьи Register, Gateway и Business нужно настроить отдельно. Подробности и ограничения API — в [руководстве MultiConnect](/plugins/multiconnect) и [матрице совместимости](/compatibility).

## Установка и управление

Для поддерживаемого пакета используйте Composer и затем следуйте его собственному README. Команды управления `master plugin:*` доступны только если установленная сборка Console содержит соответствующую команду; проверьте `php master list` перед использованием.
