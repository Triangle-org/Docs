# Плагины

Плагины подключают дополнительные возможности к приложению Triangle или Localzet Server. Наличие Composer-пакета не означает, что любая функция или интеграция плагина готова к production.

## OAuth

`triangle/oauth` использует Localzet HTTP client и Triangle Engine. Смотрите страницу [OAuth](/plugins/oauth) и сверяйте работу конкретного провайдера: публичные OAuth endpoints и требования могут изменяться независимо от пакета.

## Media — обработка изображений

`triangle/media` требует PHP Imagick extension. Установите Imagick для используемой версии PHP и проверьте поддерживаемые операции обработки в документации пакета.

## Pusher — незавершённый каркас

Плагин остаётся прототипом: конфигурация отключена по умолчанию, а полноценная обработка push-событий не реализована. Не используйте его как готовый push-сервис.

## MultiConnect — Localzet Server connection registry

`triangle/multiconnect` зависит от Localzet Server и предоставляет `GatewayServer` с реестром соединений, UID и групп внутри worker-процесса. Обработчик можно зарегистрировать как endpoint Localzet Server или явно добавить в `config/process.php` Triangle-приложения. Пакет можно использовать вне Triangle.

Реестр видит только соединения текущего worker-процесса. Межпроцессная и межузловая рассылка, эквивалентная GatewayWorker, требует broker-интеграции и в этот пакет не входит. См. README пакета и [матрицу совместимости](/compatibility).

## Установка и управление

Для поддерживаемого пакета используйте Composer и затем следуйте его собственному README. Команды управления `master plugin:*` доступны только если установленная сборка Console содержит соответствующую команду; проверьте `php master list` перед использованием.
