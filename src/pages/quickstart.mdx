# Быстрый старт

Это руководство поднимает минимальное приложение на HTTP-треке Web. Здесь используются текущие API и конфигурация репозитория `Web`; примеры для WS находятся в разделе [WebSocket-трек](/frameworks/ws).

## Создайте приложение

```bash
composer create-project triangle/web my-first-app
cd my-first-app
```

Проект требует PHP 8.2 или новее в пределах ветки 8.x и Composer. Composer сообщит об отсутствующих обязательных расширениях.

## Запустите сервер

```bash
php master start
```

Порт берётся из `SERVER_LISTEN` или `config/server.php`; в шаблоне Web это `http://127.0.0.1:8000`. Команда `php master status` показывает состояние запущенного master-процесса.

## Добавьте маршрут

Откройте `config/route.php`. Этот файл исполняется при загрузке приложения и регистрирует маршруты через фасад Triangle Router:

```php
<?php

use Triangle\Request;
use Triangle\Response;
use Triangle\Router;

Router::get('/hello/{name}', function (Request $request, string $name): Response {
    return response("Привет, $name!");
});
```

Перезапустите или перезагрузите приложение и откройте `/hello/Мир`. `Triangle\Request` и `Triangle\Response` предоставляются Engine; конкретный HTTP dispatch выполняет `triangle/engine-http`.
