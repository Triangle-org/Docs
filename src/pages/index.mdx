# Triangle Framework

Модульный набор PHP-библиотек на базе [Localzet Server](https://github.com/localzet/Server). Включает HTTP-трек Web и отдельный WebSocket-трек WS для приложений реального времени. Выбирайте нужные компоненты и проверяйте их совместимость по [матрице пакетов](/compatibility). {{ className: 'lead' }}

## Концепт проекта {{ anchor: false }}

В основе лежит [Localzet Server](https://github.com/localzet/Server), над ним расположены Engine, компоненты, специализированные движки и приложения Web/WS. В checkout 2026-11-01 приложения декларируют PHP `^8.2`, а многие библиотеки — `^8.1`; отдельные legacy-пакеты имеют другие требования. Это описание manifests, не гарантия поддерживаемой матрицы. {{ className: 'lead' }}
