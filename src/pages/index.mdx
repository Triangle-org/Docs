# Triangle Framework

Модульный набор PHP-библиотек на базе [Localzet Server](https://github.com/localzet/Server). Включает HTTP-трек Web и отдельный WebSocket-трек WS для приложений реального времени. Выбирайте нужные компоненты и проверяйте их совместимость по [матрице пакетов](/compatibility). {{ className: 'lead' }}

## Концепт проекта {{ anchor: false }}

Localzet Server предоставляет асинхронный runtime и сетевые протоколы. Triangle добавляет Engine, независимо подключаемые компоненты, HTTP-движок и отдельный WebSocket-движок. Приложения Web и WS выбирают один из этих tracks; требования к PHP и зависимостям зависят от выбранного пакета и собраны в [матрице совместимости](/compatibility). {{ className: 'lead' }}
