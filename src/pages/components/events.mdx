# Events

`triangle/events` предоставляет простой in-process event dispatcher через `support\Events`. Текущий `config/event.php` пуст по умолчанию; listeners можно зарегистрировать из bootstrap или кода приложения.

```php
use support\Events;

$listenerId = Events::on('user.registered', static function (object $user): void {
    // Handle the event in this process.
});

Events::emit('user.registered', $user);
```

Слушатели выполняются в текущем процессе. Очередь, повторные попытки и надёжная межпроцессная доставка этим компонентом не предоставляются. Пакет зависит от Engine и не заменяет брокер сообщений.
