# View

`triangle/view` выбирает renderer из `config/view.php`. Встроенный renderer `raw` доступен без дополнительного пакета; Twig, Blade и ThinkPHP template adapters подключаются optional Composer-зависимостями.

Настройка шаблона:

```php
return [
    'handler' => Triangle\View\Render\Raw::class,
    'options' => [
        'view_suffix' => 'phtml',
        'vars' => [],
    ],
];
```

В приложении используйте helper `view()`:

```php
return view('index', ['title' => 'Triangle']);
```

Фактические пути и поведение renderer зависят от шаблона, приложения и выбранной реализации. Сам пакет не требует Twig/Blade/ThinkPHP; подключайте только используемый adapter.
