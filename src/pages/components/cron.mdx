# Cron

`triangle/cron` регистрирует периодические callback-задачи через `localzet/cron` и запускает их как отдельный Localzet Server endpoint. Пакет входит в зависимости Web-сборки; WS-сборка не включает его по умолчанию.

Задачи задаются массивом `config/cron.php`. Поля, которые читает текущий `triangle/cron`:

```php
<?php

return [
    [
        'name' => 'cleanup',
        'rule' => '0 * * * *',
        'callback' => static function (): void {
            // Perform a short recurring task.
        },
    ],
];
```

Для исполнения Cron должен быть включён в bootstrap приложения и запущен через штатный master lifecycle. В конфигурации компонента нет полей `schedule` или `task`; расписание передаётся в `rule`, задача — в `callback`.
