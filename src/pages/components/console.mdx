# Console

`triangle/console` подключает консольную интеграцию Triangle поверх `localzet/console` и Engine. Пакет требует PHP `^8.2`; точный набор команд зависит от собранного application template и установленных пакетов.

## Проверка команд

```bash
php master list
```

Команды запуска сервера (`start`, `stop`, `status`, `reload`, `connections`) относятся к runtime Localzet/Triangle. Генераторы и plugin-команды доступны только если их добавляет установленная версия `triangle/console`. Используйте вывод `list` как фактический перечень в конкретном проекте.

Для ручного подключения пакета сверяйте его constraints в [матрице совместимости](/compatibility). Symfony Console и Process — прямые зависимости пакета.
