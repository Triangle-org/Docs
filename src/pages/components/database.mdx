# Database

`triangle/database` подключает Illuminate Database 11 и Eloquent к Engine bootstrap. Пакет требует PHP `^8.2`; его конфигурация использует стандартную структуру Illuminate в `config/database.php`.

```php
<?php

namespace app\model;

use Triangle\Database\Model;

class User extends Model
{
    protected $table = 'users';
}
```

```php
$users = User::query()->where('active', true)->get();
```

Для query builder и database manager смотрите `Triangle\Database\Manager` и Bootstrap исходного пакета. Пакет не объявляет фасад `Triangle\Database\DB`; примеры с таким классом к текущему API не относятся.

Доступные драйверы определяются установленными Illuminate/PHP extensions и конфигурацией. MongoDB предлагается как отдельная интеграция, она не входит в обязательные зависимости.
