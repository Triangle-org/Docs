# Session

`triangle/session` настраивает session handler Localzet Server во время Engine bootstrap. Доступны типы `file`, `mongo`, `redis` и `redis_cluster`; наличие соответствующего PHP extension/Composer клиента необходимо проверять отдельно.

Основные параметры находятся в `config/session.php`: `type`, `handler`, `config`, срок жизни и cookie attributes. Для значения по умолчанию данные сохраняются в `runtime/sessions`.

В HTTP обработчике используйте API Request или helper `session()`:

```php
$userId = session('user_id');
session(['user_id' => $userId]);
```

Это HTTP session integration. Она не является хранилищем состояния WS соединения и не синхронизирует данные между процессами автоматически.
