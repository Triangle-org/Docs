# Установка

Руководство описывает установку опубликованного HTTP-шаблона `triangle/web`. Для сборок из исходного кода используйте manifests каждого репозитория и [матрицу совместимости](/compatibility).

## Требования

- PHP `^8.2` и Composer 2.
- Обязательные PHP extensions проверяются Composer из manifests зависимостей. В частности, `triangle/engine` требует `ext-intl` и `ext-json`, HTTP Engine требует `ext-curl`.
- На Unix для управления несколькими процессами используются системные возможности PHP/ОС. На Windows Localzet Server работает в однопроцессном режиме.

Не устанавливайте `ext-posix`, `ext-mbstring` или OPcache как универсальные требования Web: они нужны отдельным интеграциям или рекомендованы для production, но не объявлены обязательными всеми базовыми пакетами.

## Установка

```bash
composer create-project triangle/web my-app
cd my-app
```

Проверьте итог установки Composer: сообщение об отсутствующем обязательном PHP extension нужно устранить в текущем PHP CLI окружении.

## Запуск и остановка

```bash
php master start
php master status
php master stop
```

Шаблон слушает `http://127.0.0.1:8000`; адрес можно изменить через `SERVER_LISTEN` или в `config/server.php`. Фоновый режим и команды управления сверяйте с `php master` и конфигурацией установленной версии.

См. также [быстрый старт](/quickstart), [команды Console](/components/console) и [совместимость пакетов](/compatibility).
